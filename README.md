# The Last of Merge: Проект для портфолио

Проект создан в целях совершенстовавания навыков создания игр полного цикла (от дизайна до публикации).
А также для демонстрации навыков.

## Архитектурный обзор
Проект построен на принципах **Data-Driven Design** и **SOLID**. 
- **Ядро:** Логика игры полностью отвязана от представления. Используется архитектура MVP.
- **DI:** Зависимости управляются через Zenject, что облегчает разработку и Unit-тестирование.
- **События:** Коммуникация между подсистемами происходит через EventBus, уменьшая связность.

## Ключевые технические решения
1. **Управление ассетами (Addressables):** 
    - Динамическая поставка контента
    - Упрощение разработки и более чистый код
2. **Аналитика:** 
    - Абстракция от конкретных аналитических сервисов
    - Поддержка нескольких сервисов аналитики, а также возможность регулировать те или иные средства аналитики при помощи RemoteConfig
3. **WebAPI:**
    - Нет необходимости держать постоянное соединение с клиентами
    - Ключевые сохранения/загрузки/синхронизации данных происходят в моменты активного пользовательского взаимодействия с игрой
    - Полностью самописное решение позволяет увеличить контроль над сервером
