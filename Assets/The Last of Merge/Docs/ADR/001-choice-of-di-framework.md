# ADR 001: Zenject как DI фрэймворк для проекта
  
## Статус
Принято
  
## Контекст
Нам нужна тулза для инверсии зависимостей (а именно для внедрения зависимостей), чтобы упростить разработку и сделать код более читаемым и лаконичным.
  
## Рассмотренные варианты
1. Кастомный фрейм - дорого, долго и излишне для данного проекта
2. VContainer - хорошее решение, однако команда незнакома с этим инструментом
3. Zenject - более тяжеловесное решение, при этом большинству разработчиков привычен данный инструмент и затраты на его внедрение будут минимальны
  
## Решение
Использовать Zenject как DI фрэймворк для проекта
