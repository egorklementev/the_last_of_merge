# ADR 002: UniTask как инструмент для асинхронности
  
## Статус
Принято
  
## Контекст
Для улучшения UX нужна асинхронность. Есть разные методы достижения этого, нужно выбрать один из них.
  
## Рассмотренные варианты
1. Корутины - быстро, дружит с Юнити, из коробки, но имеет ряд ограничений
2. async/await - может быть опасно в неопытных руках
3. UniTask - легковесный, быстрый, дружит с Юнити, команда умеет с ним работать
  
## Решение
Использовать UniTask для асинхронности
