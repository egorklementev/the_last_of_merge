# ADR 006: предварительная архитектура предметов в сумке
  
## Статус
В процессе обсуждения
  
## Контекст
Предметы и их взаимодействие - это основа все игры, поэтому очень важно выбрать
корректную архитектуру для этой core фичи. 
  
## Рассмотренные варианты
1. MVC - простое, стандартное и понятное решение, которое позволит быстро приступить к работе. Имеет ряд неудобств, связанных с особенностями Unity, которые усложняют работу.
2. MVP - чаще всего используемое решение для юнити проектов. Преимуществом является меньшее количество кода на класс, что упрощает тестирование и читаемость.
3. MVVM - тоже действенное решение, подходящее в некоторых случаях. Требует реактивного подхода, например, UniRx.
  
## Решение
Использовать MVP подход, так как он наиболее удобен для юнити проектов и позволит нам легко покрыть значительную часть кода тестами.
