# ADR 005: GameAnalytics + MyTracker как системы аналитики
  
## Статус
Принято
  
## Контекст
Чтобы лучше понимать поведения игроков, требуется инструмент аналитики. Есть много разных готовых решений, из которых нужно выбрать одно или несколько.
  
## Рассмотренные варианты
1. [GameAnalytics](https://www.gameanalytics.com/) - отличное, golden standard решение. Бесплатно до определенной степени использования.
2. [MyTracker](https://docs.tracker.my.com/ru/sdk/unity/api) - "нашенское" решение, легко внедрить и использовать. Бесплатный, без ограничений.
3. [DevToDev](https://docs.devtodev.com/integration/integration-of-sdk-v2/sdk-integration/unity) - мощное, но платное решение. Небольшой опыт у команды есть.
  
## Решение
Использовать GameAnalytics + MyTracker для аналитики, потом можно будет расширить пул средств для аналитики.
