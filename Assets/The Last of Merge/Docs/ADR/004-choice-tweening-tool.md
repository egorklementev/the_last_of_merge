# ADR 004: DOTween как твинер
  
## Статус
Принято
  
## Контекст
Для упрощения разработки требуется программный аниматор
  
## Рассмотренные варианты
1. [PrimeTween](https://github.com/KyryloKuzyk/PrimeTween) - будущий стандарт, лучшие показатели производительности, стоит изучения и внедрения на новых проектах
2. [DOTween](https://dotween.demigiant.com/) - текущий стандарт, почти каждый знает об этом инструменте, опыт у команды значительный
  
## Решение
Использовать DOTween для анимирования из кода
