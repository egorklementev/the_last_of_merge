# ADR 003: ASP .NET WebAPI для серверной логики
  
## Статус
Принято
  
## Контекст
Для сохранения прогресса и для взаимодействия игроков нужен сервер
  
## Рассмотренные варианты
1. [Photon](https://doc.photonengine.com/fusion/current/fusion-2-intro) - команда имеет небольшой опыт с этим инструментом, используется для fast-paced мультиплеерных игр с realtime взаимодействием между игроками/ избыточен для проекта
2. [Nakama](https://heroiclabs.com/docs/nakama/client-libraries/unity/) - хорошее опенсорс решение, однако потребуется заложить время на изучение и тесты
3. ASP .NET WebAPI - легко обращаться к серверу, тотальный контроль над данными и логикой
  
## Решение
Использовать ASP .NET WebAPI + PostgreSQL
