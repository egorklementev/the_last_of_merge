# Игровой цикл

## Сбор ресурсов
Игрок отправляет своего персонажа из убежища на сбор ресурсов (на манер Fallout Shelter).
По прошествии времени, персонаж приходит обратно и приносит ресурсы. Ценность и количество
ресурсов зависит от экипировки и уровня персонажа. Персонаж уходит на кулдаун, игрок может
мержить ресурсы, чтобы создавать предметы и использовать их.

## Мерж механика
С новыми ресурсами игрок может экспериментировать и мержить их между собой.
Можно получать и улучшать экипировку. Не всегда мерж делает новый предмет, можно улучшить уже
существующий. Предметы не стакаются (для простоты). Хранить предметы можно во всех слотах,
но только те, что в слотах экипировки, влияют на характеристики игрока.
Также можно крафтить специальные предметы, которые хилят, баффают самого персонажа.
Например, можно скрафтить сэндвич и перетащить его на игрока. Сэндвич исчезнет, игрок получит
очки здоровья.

## Цикл
Потраченные ресурсы можно вновь заполучить в новой вылазке. Потом можно будет добавить
клановые войны, захват территорий, пвп между игроками.
