# Основной игровой экран

## Разбиение на элементы
Так как игра позиционируется как мерж предметов, 
основной акцент делаем на пространстве для мержа (2/3 экрана). 
Слотов сделаем 35 = 5 * 7. Это довольно удобный формат: есть 
достаточно много слотов для хранения, предметы достаточно
большие для рассмотрения и комфортного перетягивания.
[См. концепт](../Images/concept_1.png)

## Экипировка
Верхнюю треть экрана будет занимать персонаж со слотами экипировки.
Предметы в слотах экипировки непосредственно влияют на характеристики
персонажа. Всего будет 8 слотов без ограничений на тип предметов, то есть
хранить можно будет что угодно в любом порядке.

## Характеристики
Характеристики персонажа можно будет посмотреть в отдельном
всплывающем окне.
