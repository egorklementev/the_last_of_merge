# Основной экран

## Страница рецептов
Отображает все открытые рецепты предметов, а также названия предметов.

## Страница рюкзака
Отображает пространство для крафта, для экипировки и для иконки персонажа.
В некоторых ситуациях показываются всплывающие нотификации.

## Страница вылазки
Отображает статус текущей вылазки, даёт возможность начать новую вылазку.
Показывает результат последней вылазки.
